# 『天つ階』・問八工房 構想メモ

更新日：2026年8月19日

## 1. ゲームタイトルと基本構想

ゲームタイトルは **「天つ階（あまつかい）」**。

階層型の世界を舞台とするが、最上階は固定しない。開発中に新しい地域・神話・伝承・異界などを追加できるよう、世界そのものを拡張可能な構造とする。

開発基盤・ゲームエンジン側は **「八百万駆動（ヤオヨロズエンジン）」**
とし、その上で動くゲーム作品が「天つ階」となる。

## 2. 階層世界

階層は単純な「上へ行くほど敵が強くなる塔」には限定しない。

-   現世
-   日本各地を題材とした地域階層
-   神域・山岳信仰領域
-   黄泉
-   地獄
-   その他、神話・伝承に由来する異界

最上階の数は決めず、必要に応じて新しい階層を追加できる設計とする。

## 3. 日本各地の神話・伝承

日本神話だけでなく、各地域に残る土着信仰・民間伝承・妖怪・神社仏閣・祭礼・昔話などをクエストやNPC、地域設定の題材として利用する。

同じ神・妖怪・信仰でも、地域によって呼称・祀り方・禁忌・性質などが異なることをゲーム内容に活かす。「唯一の正しい神話」に統一するのではなく、土地ごとに異なる伝承が同時に存在できる世界を目指す。

埼玉県だけでも、川越・秩父・河川地域・山岳信仰・神社仏閣など多数の実装候補があり、一つの県だけでも多くのクエストを構成できる。

## 4. 地獄・天界などの勢力

地獄では鬼を単純な敵種族にはしない。役人・獄卒・門番・商人・職人・一般住民など、地獄社会を構成するNPCとしての役割を持たせる。

地獄側から見れば天界側の勢力が敵になる場合もあり、天界側から見れば鬼や地獄勢力が敵になる場合もある。

「鬼＝悪」「天界＝善」のように種族だけで善悪を固定せず、場所・立場・勢力関係によって敵味方が変化する世界を想定する。

## 5. リスペクトと伝承モチーフ

好きな漫画・アニメ作品には、日本神話・妖怪・民間伝承を題材とした作品が多い。そこから興味を持った伝承を調べ、元となった神話・妖怪・信仰まで遡って「天つ階」独自のNPCやクエストへ再構成する。

基本の流れ：

1.  好きな作品でモチーフを知る
2.  元となった神話・妖怪・民間伝承を調べる
3.  「天つ階」の世界設定に合わせて独自解釈する

知っているプレイヤーだけが「もしかしてリスペクトかな？」と気づける程度の小ネタも各地に配置したい。

構想例：

-   地獄：非常に仕事のできる鬼の行政NPC
-   現世の寺：僧侶・霊・怪異などに関連する、モグラを連想させる要素
-   山・神社：狛犬をモチーフにした対の守護存在
-   神話・妖怪・伝承由来の存在を各地域へ配置

特定作品のキャラクターそのものではなく、共有されている神話・伝承モチーフを八百万側から再解釈する。

## 6. クエスト制作方針

「地域を決める → その土地の神話・信仰・妖怪・歴史を調べる →
ゲーム世界へ落とし込める要素を選ぶ →
NPC・事件・探索・戦闘・選択へ変換する」という流れを基本とする。

地域ごとの伝承差そのものをクエストにすることもできる。同系統の神・妖怪でも、別地域では接し方や作法が異なり、以前の地域で得た知識がそのまま通用しない、といった展開も可能。

## 7. 開発方針

制作環境は可能な限り無料で利用できるツールを基本とする。

中心となる環境：

-   Rust
-   Bevy
-   Blender
-   Git
-   自作Blenderアドオン
-   八百万駆動

専用ツールを整備し、将来的に共同参加者が同じ開発環境を再現しやすくする。「開発用PCと参加したい気持ちがあれば参画しやすい」環境を目標とする。

オープンソースについては、ゲーム全体を完全OSSにすると現時点で決定したわけではない。八百万駆動・汎用開発ツールのOSS化、ゲーム本体のオープン開発、画像・3Dモデル・音楽・シナリオ等の別ライセンス管理など、分離方式も検討する。

## 8. 共同開発

この世界観や開発方法そのものを面白いと思ったエンジニア・クリエイターが、将来的に共同参加できる形を目指す。

Bevy /
Rust、ネットワーク、UI、Blenderツール、3D、アニメーション、サウンド、神話・郷土史の調査など、それぞれ興味のある部分から参加できる形が理想。

開発日報や制作途中のツールを公開し、完成後ではなく「作っている途中」からプロジェクトの考え方が伝わるようにする。

## 9. 問八工房のブランドイメージ

作者のHNは
**「ししゃも」**。問八工房の魚モチーフには、成長していく存在への憧れという意味を込める。

工房全体の遊び心のあるイメージとして、**「疑似海」**という構想が生まれた。

-   問八工房：疑似的な海・水槽
-   ししゃも：そこでゲームを作る魚
-   共同参加者：海へ集まってくる仲間
-   AI：陸側・受付側で案内や制作支援をする兎
-   成果物が増える：大漁
-   新しい参加者が増える：海が賑やかになる

堅い企業イメージではなく、「楽しくものを作る工房」としての雰囲気を大切にする。

## 10. AI兎のイメージ

問八工房ではAIを制作補助・相談・情報収集などに活用する。

遊びとして、

-   ぬい：受付・制作支援をする兎
-   おり：横でネット上の情報を探し、「草（ネットの海藻）」を食べている兎

というイメージが生まれた。

「草」にはインターネットスラングの（笑）の意味も重なり、楽しく制作する工房らしいマスコットイメージとして扱える。

## 11. 問八工房の制作姿勢

最重要なのは **「楽しく作業すること」**。

雑談・アイデア出し・好きな作品や伝承についての会話も、単なる脱線ではなく、ゲーム世界・NPC・クエスト・ツール・ブランドの構想を練る時間として扱う。

必要な道具がなければ作る。面白い伝承を見つけたら世界へ追加する。疲れたら別のことをして、また作る。

完成だけを目的に制作過程を苦痛にするのではなく、作っている時間そのものを楽しめるプロジェクトを目指す。
