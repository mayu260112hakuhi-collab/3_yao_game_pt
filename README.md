# 八百万駆動（Yaoorozu Engine）

都道府県階層型和風Voxel MMO「yamatocraft」の開発を進めるための、Rust製カスタムゲームエンジンおよびシステム環境です[cite: 1]。

## 🛠️ システム要件
- **ベース言語**: Rust[cite: 1]
- **OS環境**: Windows 11 専用最適化[cite: 1]
- **専用スクリプト**: `.8g`（日本語記述スクリプトファイル）[cite: 1]
- **ゲームデータ**: `.8game`
- **シーン拡張子**: `.8wsn`

## 🗂️ アーキテクチャ
巨大化によるエディタのフリーズや破損を防ぐため、マスターシーンとサブシーンの動的分割ロード（ストリーミング）を採用しています[cite: 1]。
- `_master.8wsn`: 全体の座標原点、ローポリ背景、およびロード制御
- `_town.8wsn`: 宿場町、NPC、固定建築物ノード
- `_field.8wsn`: 地形およびエネミースポーンノード
- 
## ⚙️ 外部技術・ライブラリの活用
- **Bevy**: エンティティ管理（ECS）などの強力なパーツ・クレートを活用
- **Monaco Editor**: 日本語記述スクリプト（.8g）の快適な記述・編集環境を実現
