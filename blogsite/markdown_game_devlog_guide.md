# 🐟 『ししゃも / 間八STUDIO』個人ゲーム開発＆宣伝ポータルサイト構築ガイド

個人ゲーム開発において、**「自分の城（公式サイト・Devlogブログ）」**を持つことは、開発の記録を残すだけでなく、コアなファンを獲得し、Steam等のストアページ（ウィッシュリスト）へ誘導するための強力な武器になります。

本ドキュメントでは、**マークダウン（Markdown）形式**を活用して、効率的かつ魅力的にゲームを宣伝・発信するためのWebサイト構築手法・記事フォーマット・宣伝戦略を網羅的に解説します。

---

## 1. マークダウン式Webサイトの構成案

静的サイトジェネレーター（Hugo、Astro、Next.js + MDX、またはObsidian/Gatsby等）を利用することで、マークダウンファイルを配置するだけで高速・軽量かつ美しい開発ブログ・宣伝サイトを構築できます。

### サイトマップ構想
* **`/`（ホーム）**: メインビジュアル、最新動画、最新開発ログ、ゲームの概要
* **`/about/`（チャンネル＆スタジオ紹介）**: 『ししゃも / 間八STUDIO』のコンセプト紹介
* **`/games/`（作品一覧）**: 開発中・リリース済みのゲーム紹介ページ（Steam/DLsite/BOOTH等へのリンク）
* **`/devlog/`（開発日記記事一覧）**: マークダウンで執筆する開発記事のアーカイブ
* **`/contact/`（お問い合わせ）**: プレス・案件依頼・ファンレター用の窓口

## 3. 宣伝効果を高めるマークダウン執筆術

### ① 視覚的アイキャッチの差し込み
文脈の間に画像、GIFアニメーション、動画埋め込みをバランスよく配置します。ゲーム開発においては「動き」を見せることが最も効果的なアピールになります。

### ② 「試行錯誤（バグ・失敗談）」をコンテンツ化する
完成された情報だけでなく、「開発中に起きた変なバグ」や「数学的な計算ミスでキャラクターが吹っ飛んだ話」などをコミカルに記述することで、読者の親近感を生み出します。

### ③ SEO（検索エンジン最適化）を意識した見出し設定
`H2` や `H3` タグ（`##` や `###`）には、「ゲーム開発」「Blender 3Dモデル」「インディーゲーム Devlog」などのキーワードを自然に含めることで、検索経由の新規ユーザー獲得を狙います。

## 4. YouTube × マークダウンサイトの連動運用フロー

```
 [YouTube動画 / Shorts] ─── (短時間での拡散・認知) ───┐
                                                     ├─► [マークダウン公式サイト] ──► [Steamウィッシュリスト登録]
 [SNS (X / Bluesky)]   ─── (日々の進捗・画像投下) ───┘   (深堀り記事・高画質GIF・リンク集)
```

1. **SNS / Shorts**: 15〜30秒のインパクトある映像で興味を惹く。
2. **YouTube本編**: 開発の裏側やトークをじっくり見せる。
3. **マークダウンサイト（記事）**: 詳しい解説やコード、高品質なスクショ、関連リンクを網羅し、検索（Google）から流入する層をキャッチする。
